1. ¿Qué es un sistema operativo?

El sistema operativo es el programa principal del ordenador. Hace posible que podamos usar el equipo, abrir programas, guardar archivos y comunicarnos con los componentes físicos.

📌 Definición sencilla

Es el sistema que organiza el funcionamiento del ordenador para que el usuario pueda trabajar con facilidad.

🌍 Ejemplos

Windows · macOS · Linux · Android · iOS

Una comparación útil:
Si el ordenador fuera una oficina, el hardware serían los objetos físicos, el sistema operativo sería quien organiza todo, las aplicaciones serían las herramientas y los archivos serían los trabajos y documentos.

2. ¿Los sistemas operativos son libres o propietarios?

No todos los sistemas operativos se distribuyen de la misma forma. Una diferencia importante es si son software libre o software propietario. A veces se dice “privado”, pero el término más correcto en informática es propietario.

🔓 Software libre

Permite a los usuarios usar, estudiar, modificar y compartir el programa. Para poder estudiarlo y modificarlo, su código fuente debe estar disponible.

🔒 Software propietario

Su propietario establece las condiciones de uso mediante una licencia. Normalmente el código fuente no está disponible para que cualquier usuario pueda modificarlo o redistribuirlo libremente.

⚠️ Importante: “software libre” no significa necesariamente “software gratis”. La palabra libre se refiere a las libertades que tiene el usuario sobre el programa.

¿Y los sistemas operativos que hemos visto?

Windows

Propietario

Microsoft permite usar Windows según los términos de su licencia, pero no ofrece su código completo para que cualquier persona lo modifique y redistribuya libremente.

macOS

Propietario

Apple distribuye macOS bajo sus propios acuerdos de licencia. Incluye algunos componentes de código abierto, pero el sistema completo no es software libre.

GNU/Linux

Libre

Muchas distribuciones GNU/Linux son software libre: su código puede estudiarse, modificarse y compartirse según las licencias de sus componentes.

Android

Caso mixto

La base de Android, llamada AOSP, es de código abierto. Sin embargo, muchos móviles añaden servicios y aplicaciones propietarias, por lo que el Android que usamos habitualmente no es completamente libre.

iOS

Propietario

Apple controla su distribución y establece las condiciones de uso mediante su licencia. El sistema completo no puede modificarse y redistribuirse libremente por cualquier usuario.

💡 Qué debes recordar
GNU/Linux → libre.
Windows, macOS e iOS → propietarios.
Android → su base AOSP es abierta, pero los móviles Android suelen combinar partes abiertas y propietarias.

3. ¿Qué hace el sistema operativo?

Tiene muchas funciones, pero en clase vamos a centrarnos en estas cuatro:

⌨️ A. Permite usar los dispositivos

Gestiona el teclado, el ratón, la pantalla, la memoria, el disco o la impresora.

🧩 B. Permite abrir programas

Navegador web, procesador de textos, calculadora, aplicaciones educativas, etc.

🗃️ C. Organiza la información

Usa archivos, carpetas y unidades de almacenamiento para guardar el trabajo.

🖱️ D. Permite interactuar con el ordenador

Lo hacemos mediante escritorio, ventanas, iconos, menús y barra de tareas.

4. El escritorio

Cuando iniciamos sesión, normalmente aparece el escritorio. Es el espacio principal de trabajo.

En el escritorio puedes encontrar:

Iconos Accesos directos Carpetas Archivos Papelera Barra de tareas

Consejo importante

El escritorio no debería llenarse de archivos sin orden. Es mejor usar carpetas para organizar el trabajo.

5. ¿Qué es un archivo? ¿Y qué es una extensión?

📄 Archivo

Un archivo es una unidad de información guardada en el ordenador: un documento, una imagen, una presentación, una canción o un vídeo.

Ejemplo:
trabajo_historia.docx
trabajo_historia es el nombre.
.docx es la extensión.

🏷️ Extensión

La extensión indica qué tipo de archivo es.

.docx → documento .pdf → PDF .jpg / .png → imagen .mp3 → audio .mp4 → vídeo .pptx → presentación .txt → texto sencillo
❓ Pregunta para pensar
¿Puede una fotografía tener la misma extensión que una canción?
No, porque son tipos de archivo diferentes.

6. ¿Qué es una carpeta?

Una carpeta sirve para organizar archivos. También puede contener otras carpetas.

Medios Digitales/ ├── Documentos/ ├── Imágenes/ └── Prácticas/
Gracias a las carpetas, es más fácil encontrar el trabajo y mantener el ordenador ordenado.

7. ¿Dónde se guardan los archivos?

Los archivos siempre se guardan en algún lugar.

💾 Disco interno

Es el almacenamiento del propio ordenador.

🔌 Memoria USB

Sirve para transportar archivos de un equipo a otro.

🧱 Disco externo

Ofrece más espacio para guardar datos.

☁️ Nube

Permite guardar archivos en internet para acceder desde distintos dispositivos.

8. ¿Qué es una ruta?

Una ruta indica dónde se encuentra un archivo. Es parecida a una dirección.

Ejemplo de ruta:
Documentos > Medios Digitales > Prácticas > actividad1.docx

La ruta nos dice exactamente en qué carpeta está guardado un archivo.

9. Operaciones básicas con archivos y carpetas

➕ Crear

Hacer una carpeta nueva o generar un archivo nuevo.

✏️ Renombrar

Cambiar el nombre de un archivo o una carpeta.

📋 Copiar

Crear otra copia del archivo manteniendo el original.

📦 Mover

Cambiar el archivo de lugar. Ya no queda en la ubicación anterior.

🗑️ Eliminar

Enviar el archivo a la papelera.

♻️ Recuperar

Restaurar un archivo si sigue en la papelera.

10. Diferencia entre copiar y mover

Esta diferencia es muy importante.

Acción Qué ocurre Resultado
Copiar Se crea otra copia del archivo. El original sigue en su sitio y aparece otra copia en la nueva ubicación.
Mover El archivo cambia de ubicación. Solo queda en el nuevo lugar; desaparece del sitio anterior.

12. Buenos hábitos para organizar tu trabajo

Un ordenador puede contener miles de archivos. Por eso es importante mantener el orden.

✅ Usa nombres claros

Mejor tema1_sistema_operativo.docx que documento1.docx o finaldefinitivo.docx.

✅ Crea carpetas con sentido

Agrupa los archivos por asignatura, proyecto o tipo de contenido.

✅ No guardes todo en el escritorio

El escritorio debe estar ordenado y no lleno de archivos sueltos.

✅ Revisa antes de borrar

Comprueba qué archivo estás eliminando para evitar errores.

13. Glosario rápido

Sistema operativo

Programa principal que permite usar el ordenador.

Escritorio

Espacio principal de trabajo al iniciar sesión.

Archivo

Unidad de información guardada en el ordenador.

Carpeta

Elemento que sirve para organizar archivos y otras carpetas.

Extensión

Parte final del nombre que indica el tipo de archivo.

Ruta

Dirección que indica dónde está guardado un archivo.

Copiar

Crear una copia manteniendo el original.

Mover

Cambiar un archivo de ubicación.

Software libre

Software que permite usar, estudiar, modificar y compartir el programa.

Software propietario

Software cuyo uso está limitado por la licencia establecida por su propietario.

14. Antes de empezar la práctica

Recuerda estas tres reglas:

1. No guardes todo en el escritorio. Usa carpetas para mantener el orden.
2. Utiliza nombres claros. Así podrás encontrar tus trabajos con facilidad.
3. Comprueba antes de borrar. Evitarás eliminar archivos importantes por error.
